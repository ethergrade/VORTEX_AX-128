Photos of the ExpertKeys / Tipro EK-128, PCB, J1 connector and matrix-marking work.

## ESP32_Freenove
Photos of the received Freenove ESP32-S3 board and Freenove breakout board. Use these as the visual reference for physical pin positions.

## GUI_references
User-provided visual/reference screenshots for GUI, layer and granular design direction.

## Arduino_screenshots
Arduino IDE setup, memory/PSRAM checks and runtime validation screenshots.

## Modules
`IMG_8824.jpg` — received CD74HC4067-class 16-channel analog multiplexer module used as keyboard column scanner.

## key-art
`key-art/` contains the Keymap V1.0, a CSV inventory/correlation of the local Flaticon SVG pack, and a script that generates a local visual review index. The original third-party SVG pack and generated preview are kept local and excluded from Git; see `key-art/README.md`.

## test_evidence

Create one dated subfolder per physical prototype step:

```text
test_evidence/YYYY-MM-DD/step-name/
```

Include the minimum photos and screenshots needed to reproduce or verify the result. Phone originals stay outside Git; committed copies must not contain GPS metadata.

## Privacy note

The high-resolution phone originals are retained locally under the ignored `local-source/` folder. Canonical copies in this directory were re-encoded without location metadata before publication.
