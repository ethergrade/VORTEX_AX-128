# Test Evidence

Create one folder per bench test:

```text
YYYY-MM-DD/step-name/
```

Each result should contain the minimum useful wiring photos, Serial Monitor capture and an optional `RESULT.md` with:

- firmware commit;
- wiring used;
- expected result;
- observed result;
- pass/fail;
- next action.

Remove GPS/location metadata from phone photos before committing them.
