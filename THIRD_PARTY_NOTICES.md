# Third-Party Research Material

The VORTEX repository includes links and limited visual references used for private prototyping and technical research. Those materials are not relicensed by the root `LICENSE` and remain the property of their respective owners.

In particular:

- `assets/GUI_references/` contains user-supplied screenshots used only as interface and workflow references;
- `assets/key-art/pack/` is a local Flaticon UIcons SVG source pack used to build a filename-based correlation table and visual review index. The pack is excluded from Git because Flaticon does not permit distributing licensed assets separately from an end product. The local `FLATICON-LICENSE.txt` is retained for reference; credit UIcons by Flaticon at https://www.flaticon.com/uicons;
- DSP repositories listed in `docs/15_OPEN_SOURCE_DSP_RESEARCH.md` retain their own code, framework and asset licenses;
- no source code or audio content from those DSP repositories is vendored in VORTEX at this stage.

Before distributing a release, review or replace third-party visual references and produce a dependency-specific attribution file for every external library actually used by the firmware.
