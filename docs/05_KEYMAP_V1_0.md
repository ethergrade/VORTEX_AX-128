## First row rule

The first eight keys of Row A are specifically:

```text
A1 LAYER 1
A2 LAYER 2
A3 LAYER 3
A4 LAYER 4
A5 MUTE
A6 SOLO
A7 COPY
A8 PASTE
```

The remaining eight keys select major GUI pages.

## Note row

F1–F16 are scale-locked performance pads.

They should follow:

- selected root;
- selected scale;
- octave/range settings.

The GUI should show actual note names so the instrument can be played by ear without requiring conventional keyboard fingering.
